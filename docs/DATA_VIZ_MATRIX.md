## 5. 명시적 gap

- **F 흐름선**: 현재 원천 없음. 이동·통근·물류 OD 자료 확보 시 추가 (KOSIS 인구이동 `DT_1BPB004`가 후보).
- **시군구 A**: `INH_` 계열 시군구 표 + SGIS 시군구 경계(`lowSearch=2`) 조합으로 확장 가능. crosswalk·용량 검증 선행.
- **도로명주소**: 키 미발급. SGIS 지오코딩으로 1차 대체.
- **NGII WMTS**: 키 미활성. 활성화되면 교육용 백지도 재검토.
